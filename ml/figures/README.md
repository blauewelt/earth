# Session status figures

The standalone figures produced during working sessions and delivered in
chat — committed here (Chris, 2026-08-25: *"Are the slides and figures you
made submitted as project artefacts on github? If not, please submit them.
I'd like to pick up this work in a different Claude subscription."*) so the
work is portable: everything a future session needs lives in this repo, not
in any one chat's scrollback.

These are **status/communication figures**, distinct from the paper's
figures: `ml/paper/figs/` is generated by `ml/paper/make_figs.py` and is the
canonical, versioned source for everything the paper shows. A figure here is
a snapshot of the programme's state on the day it was made, kept as a
record; the numbers in it may be superseded by later rungs — the current
truth is always `ml/EXPERIMENTS.md`.

Only `fig_factorial2.py` still has its generator (the others were made by
transient session scripts); regenerate or extend it with
`python3 ml/figures/fig_factorial2.py` (matplotlib, no GPU, reads its
numbers from constants at the top of the file — update them from
EXPERIMENTS.md when a new rung lands). House palette: background `#fcfcfb`,
ink `#1a1a19`, series `#2a78d6` / `#eb6834`.
